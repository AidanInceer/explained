# Security

The site is static: there is no server, no account and no form that sends data. Reader data (progress, quiz answers, highlights) stays in the browser's `localStorage`.

If you find a security problem, for example a way for lesson content to run a script in the reader's browser, do not open a public issue. Use GitHub's private vulnerability reporting ("Report a vulnerability" on the Security tab of the repository). We will reply as soon as we can.
